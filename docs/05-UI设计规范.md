## 2. 布局系统

- **页面骨架**:`侧栏 112 | 内容区`;内容区 = `顶栏 44 + modeline 26 + 页面(24 边距)`。
- **页面内部**:双栏栅格 `grid2(5:4)`;窄于 900px 自动退化为单列。
- **右栏(信息密集)**:全宽监控图 → 全宽表盘行 → **两对半宽卡片**(gridPair:GPU 资讯|系统资讯、偏好|配置),默认视口一屏显示完。
- **对齐铁律**:左右栏顶部对齐;卡片标题统一字号基线;数字列右对齐;标签列定宽 96;组内居中。
- **响应式**:1920×1080 / 2560×1440 下按比例放大表盘与曲线,栅格断点不变。

## 3. 组件拆分(Figma 结构)

```
App Shell
├─ Sidebar / NavItem(icon+label, active=左竖条 3px lime + #161B22)
├─ Header(title 16 + 两侧 24px 青色装饰线 + ⓘ 按钮)
└─ Page Container(scroll, 24px 边距)
   ├─ Card(圆角 10 + 半透明 #161B22 + 描边 + 四角角标 + 标题)
   │  ├─ StatTriple(三等分:数字 38 + 标签 12;左/中/右对齐)
   │  ├─ Dial(刻度环+辉光弧+指针;动画:EMA 收敛 60fps)
   │  ├─ MultiChart(双序列曲线 + 图例当前值;60 点滚动)
   │  ├─ CurveEditor(三点拖拽 + 当前温度竖线/工作点)
   │  ├─ NeonSlider(点阵轨道 + 竖条拇指 + 辉光)
   │  ├─ SwitchBox(40×20 方块开关)/ ActButton(斜切)/ Tab(斜切)
   │  ├─ Dropdown(内联展开)/ Badge / NumField
   │  └─ KBLayout(90 键帽,三区辉光,点选→青色描边)
   └─ Toast(右下角,1.9s)
```

## 4. 逐页要点(本轮已落地)

| 页 | 优化 |
|---|---|
| 系统监控 | 三数字三等分(左组左对齐/中组居中/右组右对齐);右栏两列网格一屏全显;曲线编辑器带实时温度点 |
| LED 设备 | 色环 210;分区下拉上移至色环上方一行;亮度滑块与色环同宽;灯效行右对齐按钮组 |
| FlexiKey | 键盘图渲染修复(走 Clickable 路径);布局同栅格 |
| FlexiCharger/电池 | gridPair 半宽配对;阈值滑块 180 定宽居中 |
| CPU/GPU 超频 | 核心倍频输入双列;滑杆值标签右对齐 |
| 侧栏 | 项高 66 背景满高、图标+文字垂直居中、选中左竖条;底色 #010409 分层 |

## 5. 可访问性 / 动效

- 动效:表盘/数字 EMA 收敛(0.22 系数);toast 1.9s;拖拽点放大反馈;禁止无意义装饰动画。
- 焦点:Ctrl+1..9 直达页;所有可点区域 ≥ 28px 高。
- 失效态:数据为零显示"无数据/断电"徽章,绝不显示误导性 0。
