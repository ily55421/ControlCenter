> **v2.2 修订**:v2.1 中记录的颜色 / 圆角 / 侧栏宽度 / 断点数值与实际实现不符(例如卡片圆角实为
> 16dp、侧栏展开宽 200dp、窗口最小宽 1000dp),本版全部按 `tokens.go` 与页面实现重写,
> 并补上栅格列间距、内容最大宽度、键盘最小可读宽度、曲线列数与缺失数据状态的规则。
> 颜色 / 尺寸若有冲突,一律以 `internal/gui/tokens.go` 为唯一来源;文档只解释用途。

> 适用:原生 GUI(Gio/D3D11,`internal/gui`);`ui-preview.html` 仅为早期视觉参考,不作数值依据。

## 1. 设计 Tokens(源自 `internal/gui/tokens.go`)

### 1.1 背景与描边

| Token | 值 | 用途 |
|---|---|---|
| `colBg` | `#070A0F` | 窗口底(不用纯黑,避免 1px 描边"发光发脏") |
| `colSurface` | `#0F141C` | 卡片底 |
| `colSunken` | `#0B0F16` | 内嵌区(输入框 / 图表 / 键帽底) |
| `colBar` | `#090D13` | 侧栏与标题栏(比窗口底再深一档) |
| `colHover` | `#161D27` | 悬停底 |
| `colActive` | `#1B2430` | 选中底 |
| `colLine` | `rgba(148,163,184,.13)` | 常规描边 |
| `colLineSoft` | `rgba(148,163,184,.075)` | 弱分隔 |
| `colLineHi` | `rgba(148,163,184,.24)` | 强调描边 / 悬停描边 |
| `colTopHi` | `rgba(255,255,255,.05)` | 卡片顶边高光 |

描边一律半透明,不用纯灰实线:实线在 OLED / 低亮度屏发灰,且圆角处出硬边。

### 1.2 文本四级与语义色

| Token | 值 | 用途 | 对 `colBg` 对比度 |
|---|---|---|---|
| `colText` | `#E9EEF6` | 主文本 / 标题 / 关键数值 | ≈ 17.0:1 |
| `colText2` | `#A7B4C7` | 次级文本 | ≈ 9.4:1 |
| `colText3` | `#6B7C92` | 说明 / 表单标签 | ≈ 4.65:1 |
| `colText4` | `#4D5D72` | 页脚 / mono 小标签(装饰级,不用于正文) | ≈ 2.95:1 |
| `colAccent` | `#22D3EE` | 主操作 / 选中 | ≈ 11.0:1 |
| `colOk` | `#34D399` | 启用 / 正常 | ≈ 10.3:1 |
| `colWarn` | `#FBBF24` | 温度 / 提醒 | ≈ 11.9:1 |
| `colDanger` | `#FB7185` | 错误 / 危险 | ≈ 7.4:1 |
| `colViolet` | `#A78BFA` | 次要强调 | ≈ 8.1:1 |

对比度按 WCAG 相对亮度公式计算,数值为静态近似值(实际渲染含半透明叠加,允许 ±0.3 浮动)。
`colText3` 在卡片底 `colSurface` 上实测 ≈ 4.3:1,略低于 4.5:1 —— 因此说明文字不承担唯一信息,
状态同时用文字或形状表达。状态**不得只靠颜色**区分。

## 2. 布局系统

### 2.1 骨架

```text
┌──────────┬──────────────────────────────────────────────┐
│ 导航     │ 标题栏(shellHdrH=46)                 窗口控件 │
│ (navW)   ├──────────────────────────────────────────────┤
│          │ 设备信息栏(modelineH=26)                     │
│          ├──────────────────────────────────────────────┤
│          │ pageTopH=12 内边距                           │
│          │ 页面标题 / 说明                        状态徽章 │
│          │ 内容区(按页面类型一列或多列卡片)             │
│          │ 页脚信息条(可选)                             │
│          │ pageBotH=46 内边距   需要时右缘滚动条(12dp)  │
└──────────┴──────────────────────────────────────────────┘
```

### 2.2 断点与栅格(判断单位统一为 dp,依据**内容区可用宽度**)

| 内容区可用宽度 | 规则 |
|---|---|
| < 900 dp(`gridPairW`) | 主要内容单列;`grid2` 自动退化为纵向堆叠 |
| ≥ 900 dp | 允许双列;但任一列 < 210 dp(`halfMinW`)时仍回退单列 |
| ≥ 1320 dp(`gridWideW`) | 资讯 / 偏好类子栅格并排 |
| 任意宽度 | 内容最大宽度 1440 dp(`contentMaxW`);更宽时内容左对齐,不把卡片无限拉宽 |

`grid2(wl, wr, l, r)` 的宽度契约:

- 列间距固定 16 dp,并在两列之间**显式插入占位**,`左列宽 + 16 + 右列宽 == 可用宽度`。
- 列宽按权重 `wl:wr` 分配;权重非正时按 1:1。
- 满足 `可用宽 < 900dp`、`左列 < 210dp` 或 `右列 < 210dp` 任一条件即退化为单列。
- 卡片高度交还自然布局(`Min.Y = 0`),不把视口固定高度传导给卡片内容。

### 2.3 复杂图形的可用宽度规则

| 图形 | 规则 |
|---|---|
| 键盘图 | 渲染宽 ≥ 680 dp(`kbMinW`);卡片更窄时保持该宽度并在卡片内**局部横向滚动**(滚轮,底部显示滚动条),点击命中加滚动偏移 |
| 风扇曲线 | 按可用宽度决定并排 3 / 2 / 1 列(单列 186 dp,列距 10 dp);列宽锁死,避免列内文本吃掉 Flex 剩余空间 |
| LED 色环 | 直径 210 dp,窄卡片时按可用宽度收缩(下限 150 dp);绘制与命中用同一尺寸 |
| 滑块 | 单列宽卡片内宽度上限 360 dp(`sliderMaxW`),不跟随容器无限拉长 |
| 表盘 | 主 300×272 / 副 128×118;数值与刻度保持在绘制范围内 |

### 2.4 页面垂直填充

- 内容高度小于视口时,`scrolledPage` 把「视口高 − 内容自然高」写入 `pageSlack`;页面主体用
  `grid2Fill`(每列一张卡)或 `fillPair + colFill`(每列多张卡)把卡片撑到 `自然高 + 余量`。
- 撑高时卡片标题仍贴卡片顶部,**正文在剩余高度内垂直居中**,避免"卡片很高、内容挤在顶上"。
- 余量按"实际增长"记账,并有 1px 容差:两列等高差 1px 时不会让余量在 735/736 之间来回翻,
  否则会每帧重绘。
- 内容已经占满视口(余量 ≤ 0)时完全退回自然布局,零额外开销。

### 2.5 提示语原则

界面文案只描述**用户动作与结果**;`WMI 121/1`、`AppSettings page6`、`ControlGPU.exe`、
事件总线命令等实现细节不进常规界面 —— 它们属于日志与开发文档。诊断信息可在将来放入
"详情 / 关于"入口,不因此删除已有诊断能力。

## 3. 组件状态

| 组件 | 默认 | 悬停 | 按下 | 禁用 | 选中 / 开启 |
|---|---|---|---|---|---|
| 主按钮 `btnPrimary` | 青实底 + 深色字 | 亮度 +4% | 叠加 13% 暗罩 | 整体透明度 ~30% | — |
| 次按钮 `btnSoft` | 半透明底 + 描边 | 底 8% + 描边加强 | 同上暗罩 | 同上 | — |
| 幽灵按钮 `btnGhost` | 仅文字 | 出底 5% + 文字提亮 | 同上暗罩 | 同上 | — |
| 危险按钮 `btnDanger` | 红实底 | 亮度 +4% | 同上暗罩 | 同上 | — |
| 开关 `toggle` | 灰色内嵌轨 | 白色 3% 叠加 | 滑块动画 220ms | — | 青色轨 + 滑块右移 |
| 分段 `segmented` | 内嵌底 | 文字提亮 | — | — | 青色 11% 底 + 青描边 + 文字变色 |
| 输入框 / 下拉 | 内嵌底 + 描边 | 描边加强 | 光标 | 文字降透明度 | — |
| 状态徽章 / 胶囊 | 语义色 11% 底 + 22% 描边 | — | — | 灰(`colText3`) | — |

- 常用交互命中高度 ≥ 32 dp(按钮 32 / 控件 34);键盘键帽命中由几何统一计算,与视觉一致。
- 焦点:Tab 顺序按视觉顺序;`Ctrl+1..9` 直达页面。
- 禁用态必须能看出**原因**(相邻说明文字或徽章),不能只降透明度。

## 4. 逐页结构

| 页 | 结构要点 |
|---|---|
| 系统监控 | 页头(标题 + 模式徽章) → 模式分段 → 左列(表盘 + 三数字 + 风扇模式 + 曲线面板) / 右列(CPU 监控图 + 风扇表盘 + GPU/系统资讯 + 偏好/配置) → 页脚 |
| LED 设备 | 单列:页头 → 睡眠计时器 → 彩色背光(分区 → 色环 → 亮度 → 灯效) → LED 键盘(全宽,必要时局部横向滚动) |
| FlexiKey | 页内标签居中 → 配置档 / 键盘槽位两栏;右列拿不到 680 dp 时改为上下排列(不让键盘横向滚动) |
| FlexiCharger | 左:充电策略与阈值;右:电池状态与阈值刻度盘;窄窗策略在上 |
| CPU 超频 | 实时状态 / 功耗电压双卡 → P 核 1–10 与 E 核 1–16(分两列各 8 行)→ 底部统一按钮行 |
| GPU 超频 | GPU 资讯 / 偏移设置双卡,每条滑块配名称、当前值与单位 |
| 电池 | 电池信息 / 电池校准双卡;宽屏并排、窄屏上下 |
| 节能计划 | 实时功耗 / 阈值与调度双卡;两组调度行结构一致 |
| 偏好 | 键盘与快捷键 / 显示 / GPU 模式 / 语言四卡网格 |

### 4.1 缺失数据与状态表达

| 场景 | 判据 | 表现 |
|---|---|---|
| 电池数据缺失 | `BatteryOut.Design <= 0` | 徽章与健康判定显示"无电池数据";容量 / 循环 / 年限显示 `—` |
| 电池健康未知 | `HealthCode` 越界 | 显示"未知",不使用语义色 |
| GPU NVAPI 未就绪 | `!Ready` 且当前偏移全零 | "当前生效"显示 `—`;NVAPI 行显示"未就绪" |
| CPU 频率 / 内存频率通道缺失 | 读数为 0(无 XTU 服务的机器恒零) | 显示 `—`,不冒充 0 MHz |
| 独显断电 | 占空 / 转速 / 温度全零 | "独显已断电"徽章 + 说明,不画占位仪表 |
| 无历史样本 | 采样队列为空 | "暂无数据",不伪造趋势 |

原则:**真实零值**(如利用率 0%)照常显示;只有"读不到"才显示占位符 `—`。
若后端暂时无法区分两种状态,先维持现有行为,并在实现说明中记录该限制。

## 5. 验证要点

- 窗口:最小窗口 / 默认窗口 / 最大化 / 内容宽跨越 900 与 1320 dp 两侧。
- DPI:100% / 125% / 150% / 200%,检查文字、图形、命中区与滚动条位置一致。
- 滚动:页面垂直滚动可到达首尾;键盘局部横向滚动时点击位置与显示一致。
- 键盘:键帽标签在最小可读宽度下不被裁切;行内键位铺满渲染宽度(右侧无缺口)。
- 编号:P 核 1–10、E 核 1–16 的显示编号与 `pcoreEd` / `ecoreEd` 下标一一对应。
- 状态:加载 / 正常 / 无数据 / 失败 / 不支持 / 禁用,文字与数据来源一致。
