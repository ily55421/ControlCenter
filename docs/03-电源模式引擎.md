# 电源模式引擎(ChangePowerMode 完整序列,逆向还原)

模式值:`0 quiet / 1 pwrsaving / 2 performance / 3 entertainment / 4 quiet_plus`;持久于 AppSettings(1,1)。
真实状态唯一来源:AppSettings(1,1);切换完成后广播 `clevofnkey^202`。

## 核心下发 SetPowerMode(mode)

```
WriteAppSettings(1,1,1,mode)
switch mode:
  case 2: data=2
          if AppSettings(1,32)==1:          // DTT 开
             if DTT 驱动已装: data |= 0x80
             else: WriteAppSettings(1,32,1,{0})
          if AppSettings(4,8)==1: data |= 0x40   // TurboFan 开
          SetWMI(121, 25, data)
  case 4: SetWMI(121, 25, 0)
  default: SetWMI(121, 25, mode)   // 0/1/3 直传
```

## ChangePowerMode(type) 全序列(FnKey 实现)

1. `prePowerMode = ReadAppSettings(1,1)`
2. NV 独显断电联动:SupportNVIDIAPowerOff 且 GPU 未上电且目标为 2/3 → `cc30wk.exe 0x0013 1` 上电,1 秒
3. `SetPowerMode(type)`(见上)
4. GPU 超频联动 `Load_GPU_forFn_3(type)`:
   - quiet → 限频 limitClock_quiet;OC 关
   - pwrsaving → 限频 limitClock_powerSaving;OC 关;必要时 NV 断电(0x0013 0,需确认)
   - performance → AC:限频 limitClock_performance + OC 应用(读 (5,16,8) core/mem int16 → ControlGPU.exe set_increment);DC:OC 关
   - entertainment → 限频 limitClock_entertainment;SupportAllModeGPUOC → OC 开否则关
   - quiet_plus → NV 断电(0x0013 0)
   - 限频:`ControlGPU.exe set_lock_frequency:<freq>`(频率表来自 WMI4 sub9)
5. EnergyStar:`!SupportHW_P_state` → `SetWMI(79, m)`:quiet/entertainment→2, performance→0, pwrsaving/quiet_plus→1
6. 托盘图标更换(logo_quiet/powersaving/performance/entertainment)
7. ASPM:各模式 ASPM_AC/DC(WMI4 sub15 表 off2-8);无表 → quiet/ps/ent Set_ASPM(2), performance Set_ASPM(0)
8. Windows 电源计划 Set_PowerPlan(表来自 WMI4 sub29):
   - 值 0 → Balanced {381b4222-f694-41f0-9685-ff5bb260df2e}
   - 值 1 → HighPerformance {8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c}
   - 值 2 → PowerSaver {a1841308-3541-4fab-bc81-f71556f20b4a}
   - PowerSetActiveScheme(0, GUID)
9. AMD 平台(ClevoID 20720/20724):按模式+AC/DC 取 AMD PPT/TDC/EDC 表(WMI17[208..255] 或 WMI4 sub16)→ `pcc.exe <PPT> <TDC> <EDC>`;SetLowBatteryLevel(15)/Critical(10)/Reserve(12)
10. 风扇联动 `Load_FanMode_forFn_3(type)`:
    - Support_Keep_SituationalMode_Data:读各模式 FanMode/FanOffset((4,70..77))→ 写当前 (4,5)/(4,7) + SetWMI(121,1,fanmode) + SetFanOffset;模式 3 且 Noiseless → SetWMI(121,1,8)
    - 旧方案:0/1/2 → FanMode=0;3 → MaxQ(5) 或 0;写 (4,5)
11. 刷新率联动(EPSON/低刷面板):performance+AC 且前一模式 1/4 → 恢复高刷;0/1/4 → 低刷(40Hz)
12. MCJ PeakShift(可选)
13. 结束:菜单恢复;广播 `clevofnkey^202` ×2;XTU 触发(SupportCPUOC → 写 (6,32) 等并通知 CC30_BG.exe 执行)

## 模式循环(Arg001^89 / 托盘)

NextMode 链:quiet→(Performance?2 : Entertainment?3 : PowerSaving?1);pwrsaving→(Quiet?0 : 2 : 3);
performance→(Entertainment?3 : PowerSaving?1 : QuietPlus?4 : Quiet?0);entertainment→(QuietPlus?4 : PowerSaving?1 : Quiet?0 : 2)。
切换后 3 秒忽略后续事件(IgnoreEventTimer)。

## Windows 电源计划操作

- 枚举:PowerEnumerate(ACCESS_SCHEME) + PowerReadFriendlyName
- 激活:PowerSetActiveScheme(NULL, GUID)
- 亮度:PowerWriteACValueIndex/DCValueIndex(子组 VIDEO_SUBGROUP {7516b95f-f776-4464-8c53-06167f40cc99},设置 DEVICE_POWER_POLICY_VIDEO_BRIGHTNESS)+ PowerSetActiveScheme
