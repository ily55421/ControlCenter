# ControlCenter Go 重构 — 架构与组件映射

本项目是 Clevo/Insyde **Control Center 3.0 Package v7.022** 的完整 Go 语言还原与重构。
逆向来源:`C:\soft\04_ControlCenter_7.022\04_ControlCenter`(安装包)与
`C:\Program Files (x86)\ControlCenter`(运行目录),包括 .NET 反编译(ILSpy)与原生二进制
反汇编(radare2)还原出的 ACPI 桥驱动 IOCTL 协议、事件日志 IPC、全部 WMI 命令与
AppSettings NV 存储布局。

## 原组件 → Go 组件映射

| 原组件(技术) | Go 组件 | 说明 |
|---|---|---|
| AcpiBridge.sys / AcpiBridge1.sys(KMDF) | **不重写**(内核驱动无法用 Go 实现;继续使用原驱动) | Go 通过还原出的 IOCTL 协议直接通信 |
| InsydeDCHU.dll(原生 x64) | `internal/acpibridge` | IOCTL 0x322400/04/08/0C 客户端,等价 6 个导出函数 |
| DCHUService.exe(.NET 服务) | `cmd/ccservice` | Windows 服务:热键事件源(Arg001)、进程执行通道(w_arg253/254/255)、会话管理、开机拉起托盘 |
| FnKey.exe(UWP 托盘/OSD) | `cmd/ccfnkey` | 托盘图标+菜单、OSD、电源模式引擎、热键处理、键盘灯/风扇/飞行模式/触摸板/摄像头控制、睡眠恢复联动 |
| ControlCenter30.exe(UWP 主界面) | `cmd/ccapp` | 应用启动器(磁贴)+ 电源模式页 + 偏好设置(FlexiCharger/WinFn/蓝光/WinKey/GPU 切换/PgUpDn) |
| FanSpeedSetting.appxbundle | `cmd/ccfan`(及 ccapp 内嵌页) | 风扇模式/转速曲线/防尘/实时监控 |
| Flexikey.appxbundle(CC.exe) | `cmd/ccflexikey` | 宏键(键盘/鼠标过滤驱动)、配置 profile.xml、按键统计 |
| Keyboard.appxbundle | `cmd/cckeyboard` | 键盘灯(白光/RGB 三区/Perkey/RGB15/X170 灯带) |
| CPU_OC.appxbundle(CPUOC2.0.exe) | `cmd/ccpuoc` | CPU 超频(PL1/PL2/倍频/电压/VR,Intel XTU 通道 + AMD) |
| GPUOverclocking.appxbundle | `cmd/ccgpuoc` | GPU 超频(核心/显存偏移,NVAPI 通道) |
| BatteryUtility.appxbundle | `cmd/ccbattery` | 电池信息/健康判定/校准状态机 |
| EnergySave.appxbundle | `cmd/ccenergy` | 功耗监控 + 节能调度(充放电阈值/时间表) |
| CClnk / RunAutoInstall / RemoveAPP / AddFn / clean / WakePanelUp_Hook | `cmd/ccutil` 子命令 | 捷径创建、Appx 预配、应用移除、Fn 菜单、清理、面板唤醒钩子 |
| clevomof/PowerBiosServer 注册表桥 | `internal/eventbus` | 事件日志 IPC 兼容实现 |

## 分层

```
cmd/*            进程入口(服务 / 托盘 / 各功能 UI)
internal/win32   纯 syscall Win32:窗口、托盘、OSD、热键钩子、电源 API、CoreAudio 简化
internal/ui      内嵌 HTTP UI(各功能面板,浏览器/WebView 呈现)
internal/powermode, fan, keyboard, flexikey, battery, energysave, gpu, cpuoc
                 硬件域逻辑(与原版逐命令对齐)
internal/acpibridge / appsettings / wmi / eventbus / smbios
                 基础设施(协议层,带编码单元测试)
```

## UI 策略

- **托盘与 OSD**:原生 Win32(syscall):Shell_NotifyIcon、分层置顶窗口、GDI AlphaBlend。
- **功能面板**:内嵌 HTTP 服务 + 网页(风扇曲线、RGB 调色、超频滑杆等富交互在 Web 上实现),
  首页磁贴对应原 8 个 UWP 应用,每个功能页完整复刻原控件与调用序列。
- **进程模型**:ccservice(系统服务,唯一硬件事件源)→ ccfnkey(用户会话托盘,电源模式引擎)
  → ccapp/ccfan/...(按需打开的功能面板,均为同一 Web UI 的路由)。

## 硬件访问栈

```
功能逻辑 → internal/wmi(SetWMI 编码/包命令) ─┐
          → internal/appsettings(页/偏移) ──┼→ internal/acpibridge → AcpiBridge.sys(IOCTL)
          → 事件等待(EventLoop)────────────┘
```

依赖:`golang.org/x/sys`(其余全部标准库)。
